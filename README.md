# 清帳

簡潔的個人記帳網站。記下收入、支出和轉帳，用沖銷算出真正花掉的錢，並可自訂每期從哪一天開始（包括「上個月最後一日」）。

## 本機執行

```bash
npm install
npm run dev
```

## 跨裝置

- 未登入時，帳本只留在這台瀏覽器。
- 用同一個 Google 或 X 帳號登入後，變更會跟帳號走。另一部裝置登入同一個帳號，即可打開同一本帳。
- 這個 repo 只有程式碼，不含你的帳本資料。

## 記帳方式

支出可以標成「計入預算」。同事退回的錢記成收入，並指定沖某一筆支出或某個分類。進度以淨額計算，原本的紀錄仍會保留。被沖掉的金額會標成「代收沖銷」，不會當成你賺到的收入；錢仍會進到收款戶口。
